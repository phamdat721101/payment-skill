# Read-only DeFi rollover research engine

**Spec ID:** SPEC-2026-0320

## Architecture

- **Pattern:** read-only analysis orchestrator behind the declarative tool registry
- **Isolation boundaries:** No wallet access, calldata generation, signing, flash-loan selection, relay dispatch, or broadcast.

### Execution flow

1. Validate tool input with Zod.
2. Fetch the current Morpho position and supplied candidate market summaries.
3. Evaluate LTV, health, maturity, carry, and capacity evidence.
4. Return a provenance-labelled, non-executable research intent.

## Data contracts

```json
{
  "inputs": {
    "chain": "ethereum-mainnet | base-mainnet | arbitrum-one",
    "current_market_id": "32-byte Morpho market ID",
    "candidate_market_ids": "1-10 caller-supplied Morpho market IDs",
    "risk_policy": "integer basis-point and health-factor thresholds"
  },
  "outputs": {
    "current_position": "base-unit strings, LTV bps, health factor, and provenance",
    "candidates": "liquidity, utilization, capacity status, and deterministic rank",
    "rollover_intent": "explicitly non-executable requirements and blockers"
  },
  "error_states": [
    "MORPHO_SDK_MISSING",
    "INVALID_MARKET_ID",
    "CANDIDATE_UNAVAILABLE",
    "LOAN_ASSET_COMPATIBILITY_UNVERIFIED",
    "PINNED_BLOCK_UNAVAILABLE"
  ]
}
```
